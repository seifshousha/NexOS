# NexOS

A modern desktop operating system simulator built with Python, FastAPI, HTML, CSS, and JavaScript.  
NexOS simulates the core experience of an operating system through a web-based desktop interface with a virtual file system, terminal, and system applications.

---

## 📖 Overview

NexOS is an educational operating system simulator that demonstrates how desktop environments, file systems, terminals, and backend APIs work together.

The project combines a Python backend with a responsive web frontend to create an interactive desktop environment that runs in the browser.

---

## ✨ Features

- 🖥️ Interactive desktop interface
- 📂 Virtual file system
- 💻 Built-in terminal with shell commands
- 📁 File Manager
- ⚙️ Settings application
- 🧮 Calculator
- 📊 System Monitor
- 📜 Log Viewer
- 🎨 Modern responsive UI
- 🔄 REST API communication between frontend and backend

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/seifshousha/NexOS.git
```

### 2. Open the project

```bash
cd NexOS
```

### 3. Install dependencies

```bash
pip install fastapi uvicorn
```

### 4. Run the server

```bash
python run_server.py
```

### 5. Open your browser

```
http://localhost:8000
```
